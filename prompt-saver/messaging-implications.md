# Messaging Implications: Prompt Saver
*Skill: startup-positioning | Generated: 2026-04-02*

## Messaging Hierarchy

Every piece of copy should follow this priority:

1. **The pain** — "Your prompts are scattered. You keep rewriting ones you already perfected."
2. **The outcome** — "Save any prompt. Find it in seconds. Every edit is versioned."
3. **The differentiator** — "Free. No account. No setup. Works instantly."
4. **The proof** — "Automatic versioning, full-text search, tags, favorites."
5. **The access** — "Open Prompt Saver → start saving prompts."

Not every piece of copy needs all levels. But when present, they should appear in this order.

## Category Label

**Always use:** "Prompt Library"

Use this exact phrase consistently across: website hero, README, social bios, Product Hunt, any marketplace listing.

Do NOT use: "Prompt Management Platform" (triggers enterprise expectations), "Prompt Engineering Tool" (dying buzzword), "AI Tool" (generic, triggers fatigue).

## Value Anchor

**"What a well-organized Notion workspace does for your prompts — but with versioning and instant search, for free."**

Where to use: body copy, comparison sections, "how it works" explanations.
Where NOT to use: headlines, taglines (too long).

## Customer Language vs. Category Language

| Customer says (use as verbs/hooks) | Category says (use as outcomes) |
|---|---|
| "I keep losing my prompts" | Prompt library |
| "Scattered across Notion and chat history" | Organized collection |
| "I rewrote it from scratch" | Automatic versioning |
| "I had a perfect prompt but can't find it" | Instant search |
| "Prompts are reusable assets" | Prompt library |
| "Yet another tool I don't need" | Free, no signup, zero friction |

**Bridge in copy:** Use customer verbs in headlines ("Stop losing your best prompts"), category nouns in descriptions ("Your prompt library with versioning and search").

## Words to Use / Avoid

| Use | Instead of | Why |
|-----|-----------|-----|
| prompts | prompt engineering | Buzzword is dying, replaced by "context engineering" |
| save, find, version | manage, orchestrate, deploy | Enterprise language, wrong expectations |
| library | platform, suite, workspace | "Library" = lightweight. "Platform" = heavy. |
| free | freemium, open-source, free tier | "Free" is cleaner. "Freemium" implies limits. |
| your prompts | our product, we offer | User-centric, not company-centric |
| instantly, in seconds | with ease, seamlessly | Specific > vague. Time-based > adjective-based. |
| every edit is versioned | version control | "Version control" = Git = complex. "Every edit is versioned" = automatic. |

## Words to NEVER Use on the Marketing Page

| Word | Why |
|------|-----|
| IndexedDB | Implementation detail, meaningless to users |
| local-first | Technical architecture choice, not a benefit |
| Next.js, React, Tailwind | Users don't care about your stack |
| SaaS, B2B, B2C | Internal business model labels |
| AI-powered | Prompt Saver doesn't use AI — it organizes prompts |
| Unlock, supercharge, leverage | AI slop verbs |
| Comprehensive, robust, seamless | Empty adjectives |

## Red Flags
- "Free forever" claims can erode trust if monetization comes later. Say "free" not "free forever."
- Avoid comparing directly to PromptLayer/Langfuse by name on marketing — positions you as a smaller alternative rather than a different category.
