# Intake: Prompt Saver

*Skill: startup-positioning | Generated: 2026-04-02*

## Product
Prompt Saver — a local-first web tool for saving, versioning, and searching LLM prompts. Browser-based, IndexedDB storage, no server database needed.

## Problem
Developers who write structured LLM prompts (hiring evaluators, code reviewers, document analyzers) have no dedicated tool to organize them. Prompts are complex documents (500-2000 chars) with embedded instructions, evaluation criteria, and output formats. They get lost, duplicated, or rewritten from scratch.

## Target User
Individual developers and AI practitioners who write 10+ structured prompts and reuse them regularly. Currently at Maitri (internal tool), but applicable to any developer working with LLMs daily.

## Current Alternatives (what they do today)
- Copy-paste from Notion/Google Docs
- Scroll through ChatGPT/Claude conversation history
- Keep .txt files in random folders
- Rewrite prompts from memory each time
- GitHub gists or repos (version control but no search/tagging)

## Best-Fit Customer
Someone who writes complex, multi-section prompts with evaluation criteria and output formats, reuses them across projects, and has been burned by losing a good prompt or not being able to find it when needed.
